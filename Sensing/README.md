# GreenThumb - Sensing


## Description

This directory contains all software related to interfacing with sensors on both legged robots and soil sensors used to collect data for the GreenThumb project.


### Supported Platforms


#### Legged Robots

- Unitree B1
    - [Unitree Manual][https://static.generation-robots.com/media/user-manual-b1-unitree-robotics.pdf]


#### Soil Sensors

- TEROS-12
